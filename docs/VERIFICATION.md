## 核心语义与迁移

- 包名及用户隔离；任一、全部、排除、字段选择、空文本、大小写和正则。
- 未选择应用时，即使关键词匹配也不执行消除或转发；移除全部应用后，未执行的旧消除任务取消。新规则默认启用、5 秒消除并包括常驻通知，已有显式配置保留。
- 标题/正文的中文、引号、换行、&、#、+ 在 URL 和 JSON 中保持正确内容。
- 同一短信命中转发和消除；队列持久化后按 4 秒请求消除。
- 重复回调不重置消除时间；内容更新导致旧修订失效并重新匹配。
- 多规则消除合并；删除/关闭最早来源后重新计算其他来源截止时间。
- 提供真实脱敏 FilterBox 导出，逐条核对四条规则的应用范围和未迁移项；内部枚举、有效星期/充电/屏幕限制必须阻止启用。
- 全部消除忽略残留文本；部分消除重新确认字段；通知按钮操作不迁移。
- 未配置导出目录时不可导出；选择目录后重启应用仍可导出，撤销目录授权后提示重新选择。文件名与到点啦一致，前缀为 NotifyBox。
- 完整导出保留规则状态、URL、正文、鉴权头、Bot Token；导入后新 ID 正确关联，配置重新加密，规则默认关闭。旧 v1 文件仍能导入并提示缺少配置。
- 从已有 v1 数据覆盖升级，保留规则、凭证、通知、队列与设置；确认 Room KSP 生成及实际迁移成功。

## 网络与设备

- 通用 HTTP 成功、Telegram ok=false、认证失败、429 与 Retry-After 秒数/日期。
- 代理节点中断后发出一条失败提醒；持续重试更新同一记录的次数、上次时间和下次时间；恢复代理后成功。HTTP/SOCKS 与系统 VPN 分流分别检查。
- 超时、响应不完整、5xx、发送中断在持续重试开启时会重试，可能重复接收；关闭后结果未知等待手动操作。认证错误停止，修改配置后手动重试仍在原记录。
- 暂停待发送任务；立即重试不等待旧延迟任务；连续点击和多个 Worker 同时调度只允许一次数据库 claim。
- 断网保留队列，服务端 429 的等待时间不得提前；进程中断恢复发送队列，重试次数不清零。
- 不跟随重定向；不得在日志展示原始 URL、响应描述或异常消息。
- 小米 13 亮屏、锁屏、最近任务划掉、进程终止、重启、自启动与电池限制。
- 核心验收：启用短信 5 秒消除 → 划掉最近任务 → 收短信 → 不打开 NotifyBox，检查通知约 5 秒后移除；熄屏后重复。设置页确认监听连接、后台服务和权限检查表。
- 延迟途中进程回收/监听断开后恢复，按原截止时间执行；同内容回调不重置，更新内容不能被旧任务移除，重连不重复转发已记录通知。
- user=999 的微信通知单独验证；分组摘要和缺失标题/正文如实记录。
- 常驻和系统通知能否消除取决于系统；消除不能保证屏蔽首次横幅和声音。

## 导航和界面

- 左/右边缘、系统返回键和连续返回；取消预测手势不能提交页面返回。
- 设置切换 6 种主题色、RGB 滑块及六位色值输入，应用后四个标签页、按钮、标签、导航及编辑页同步换色；重启保持，恢复默认还原原始雾蓝。自定义弹窗取消/返回不改当前主题，非法色值不可应用，切换保留页面和编辑状态。ThemeSettings.kt 提供主题色对比 AS Preview，未渲染或真机验证。
- 键盘先收起，弹窗先关闭；编辑返回先确认未保存修改。
- 从记录详情创建规则，保存或放弃后回详情，再回记录；保留列表位置与筛选。
- 记录卡片任意位置可打开详情；不再展示包名、用户编号、key、修订和分组；记录/转发各 20 条每页，切页、筛选、返回保持合理位置。
- 一条通知到达后手动或自动移除，列表仍为同一条，详情补充移除时间和状态；重复移除回调不增加记录。旧版独立移除项不显示且不计入分页总数；无匹配规则的通知同样处理。相同 key 重新到达是新记录，旧内容的迟到移除不能标记新内容，移除后监听重连再收到同内容也应按新通知处理。
- 权限返回设置页后自动刷新勾选；自启动/厂商电池策略/最近任务锁定手动记录重启后保留；失败提醒被禁用时能在权限列表看到。

- 长中文、长包名、窄屏、放大字体；选中、禁用、错误、加载、空状态及 Token 默认隐藏。
- 到点啦原版浅蓝紫背景、藏蓝文字、系统衬线标题、白色细边框卡片与主按钮圆角；不引入提醒业务。

- 延迟 0、0.5、4、86400 秒，原有非整秒延迟、空值及超过范围的错误；保存失败时错误进入可见区域。
